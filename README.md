## About this repository

This repository holds both the Jupyter notebook source (`.ipynb`) and the
rendered pages (`.html`) for the course notes. The notebooks are provided for
anyone who wants to download and run them locally:

```
git clone https://github.com/WilliamIngle6319/Math511.git
cd Math511
jupyter lab
```

Custom styling and macros are supplied by a JupyterLab extension, so locally
rendered notebooks may not match the published pages exactly.

## Additional resources

[3Blue1Brown — The Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra)
A series of short videos by Grant Sanderson exploring the fundamental ideas of
linear algebra with visualization and context.

[A Vision of Linear Algebra](https://ocw.mit.edu/courses/res-18-010-a-2020-vision-of-linear-algebra-spring-2020/)
MIT Open Courseware's full course, including video lectures, featuring
Professor Gilbert Strang. These notes take inspiration from his lectures.
